The bootable USB stick must be organised in this way when you format the computer, and obviously it must be connected to a wired internet connection.

> CODE P11

```text
Pendrive/
├── boot/
├── efi/
├── sources/
├── Autounattend.xml
├── setup.exe
└── Windows-Installer/
    ├── config/
    │   └── programs.json
    └── scripts/
        ├── installers.ps1
        └── main.ps1
```
